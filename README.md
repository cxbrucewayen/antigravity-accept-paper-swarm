## Overview / 项目简介

基于 **Google Antigravity /swarm** 构建的全自动化科研论文全周期多智能体系统——一体打通 **论文初稿撰写 + 模拟审稿人对抗评审（Peer-Review Simulation） + 真实审稿意见增量修稿与回信（Revision & Response Letter）**。

> **Status**: Repository initialized and open-sourced under MIT. Architecture design and multi-agent /swarm implementation in progress.
