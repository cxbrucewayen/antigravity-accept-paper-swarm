- **Strict Domain Trigger (Multi-Swarm Coexistence)**: Do **NOT** hijack unrelated `/swarm` sessions. Only when `/swarm` is active **and** the user explicitly mentions `accept-paper-swarm` (or the task clearly matches this plugin's target domain: `academic paper writing, adversarial peer-review simulation, manuscript revision, and point-by-point reviewer rebuttal letters`), immediately read and follow the `accept-paper-swarm` orchestrator skill (`skills/accept-paper-swarm/SKILL.md`).
